BAB III
Virtual Private Server (VPS)

Pada bab ini akan dijelaskan secara rinci proses deployment aplikasi Moneygement ke lingkungan produksi menggunakan layanan Virtual Private Server (VPS) dari Google Cloud Platform. Proses ini mencakup pembuatan instance server, konfigurasi sistem operasi, instalasi software pendukung, hingga pengujian aplikasi yang berjalan di server produksi.

Pemilihan Platform Hosting
	Dalam memilih platform hosting untuk aplikasi Moneygement, tim pengembang mempertimbangkan beberapa faktor penting seperti reliabilitas, skalabilitas, keamanan, dan biaya operasional. Setelah melakukan evaluasi terhadap berbagai penyedia layanan cloud, dipilihlah Google Cloud Platform (GCP) dengan layanan Compute Engine sebagai solusi hosting yang optimal.
	Google Cloud Platform menawarkan beberapa keunggulan yang sejalan dengan kebutuhan aplikasi Moneygement:
Infrastruktur Global: GCP memiliki data center di berbagai lokasi termasuk Asia Tenggara (Singapore) yang dekat dengan target pengguna di Indonesia, sehingga latensi akses dapat diminimalkan.
Free Tier: GCP menyediakan program free tier yang memungkinkan penggunaan instance e2-micro secara gratis untuk pengembangan dan testing.
Keamanan Terintegrasi: Sistem keamanan bawaan seperti firewall, IAM, dan enkripsi data memberikan perlindungan berlapis terhadap aplikasi.
Skalabilitas: Kemampuan untuk meningkatkan spesifikasi server sesuai kebutuhan tanpa downtime yang signifikan.

Persiapan Akun Google Cloud
	Sebelum memulai proses deployment, langkah pertama adalah menyiapkan akun Google Cloud Platform dengan mengikuti prosedur berikut:
Akses Console: Buka browser dan kunjungi alamat https://console.cloud.google.com/ kemudian login menggunakan akun Google.
Aktivasi Free Trial: Untuk pengguna baru, Google menyediakan kredit gratis sebesar $300 yang berlaku selama 90 hari. Aktivasi memerlukan verifikasi kartu kredit/debit namun tidak akan dikenakan biaya selama masih dalam batas free tier.
Pembuatan Project: Klik dropdown project di header, pilih "New Project", masukkan nama project "MoneyGement", lalu klik "Create".

Pembuatan VM Instance
	Virtual Machine (VM) Instance merupakan server virtual yang akan menjalankan aplikasi Moneygement. Proses pembuatan VM dilakukan melalui layanan Compute Engine dengan konfigurasi sebagai berikut:

Akses Compute Engine
Pada menu hamburger (☰) di pojok kiri atas console, scroll ke bawah dan pilih "Compute Engine" kemudian "VM instances". Jika ini adalah penggunaan pertama, klik tombol "Enable" untuk mengaktifkan Compute Engine API dan tunggu beberapa menit hingga proses aktivasi selesai.

Konfigurasi Firewall
	Firewall berfungsi mengontrol lalu lintas jaringan yang masuk dan keluar dari VM instance. Untuk memastikan aplikasi dapat diakses dari internet, perlu dikonfigurasi rules yang mengizinkan traffic pada port yang diperlukan.
	Akses menu "VPC Network" kemudian "Firewall" melalui hamburger menu. Klik "CREATE FIREWALL RULE" untuk membuat rule baru dengan parameter yang disesuaikan untuk kebutuhan web server.

Akses SSH ke Server
	Secure Shell (SSH) merupakan protokol untuk mengakses server secara remote dengan aman. Google Cloud Console menyediakan fitur SSH browser yang memudahkan admin untuk masuk ke terminal server tanpa perlu konfigurasi tambahan.
	Pada halaman VM instances, klik tombol "SSH" di baris VM moneygement-server. Browser akan membuka jendela terminal baru yang terhubung langsung ke server.

│                                                                             │

│                                                                             │
│     index index.php;                                                        │
│     charset utf-8;                                                          │
│                                                                             │
│     location / {                                                            │
│         try_files $uri $uri/ /index.php?$query_string;                      │
│     }                                                                       │
│                                                                             │
│     location = /favicon.ico { access_log off; log_not_found off; }          │
│     location = /robots.txt  { access_log off; log_not_found off; }          │
│                                                                             │
│     error_page 404 /index.php;                                              │
│                                                                             │
│     location ~ \.php$ {                                                     │

│                                                                             │
│     location ~ /\.(?!well-known).* {                                        │

Konfigurasi HTTPS (SSL) dengan Certbot
	Untuk mengamankan transaksi data pengguna, aplikasi perlu menggunakan protokol HTTPS. Kita akan menggunakan Let's Encrypt dan Certbot untuk mendapatkan sertifikat SSL gratis secara otomatis.
	Syarat utama: Anda harus memiliki domain (contoh: moneygement.my.id) yang sudah diarahkan ke IP Server (34.124.226.208).

Instalasi Certbot
Instal paket Certbot dan plugin Nginx.

Tabel 3.33 Command Instalasi Certbot
┌─────────────────────────────────────────────────────────────────────────────┐
│ $ sudo apt update                                                           │
│ $ sudo apt install certbot python3-certbot-nginx -y                         │
├─────────────────────────────────────────────────────────────────────────────┤
│ Output:                                                                     │
│ Reading package lists... Done                                               │
│ Setting up certbot (2.9.0-1ubuntu0.1) ...                                   │
└─────────────────────────────────────────────────────────────────────────────┘

Gambar 3.27 Output Instalasi Certbot

BAB I
Aplikasi Manajemen Keuangan (Moneygement)
Definisi
Aplikasi Moneygement
Moneygement merupakan aplikasi manajemen keuangan pribadi yang membantu pengguna mencatat, mengelola, dan menganalisis pemasukan serta pengeluaran secara praktis dan otomatis agar pengguna lebih memahami pola pengeluaran dan dapat mengontrol serta mengatur keuangannya secara mudah dan efisien.
Gemini API
Gemini API merupakan layanan kecerdasan buatan yang digunakan untuk memproses dan menganalisis data secara otomatis, seperti memahami teks, mengelompokkan informasi, serta menghasilkan rekomendasi berbasis AI.
Gmail API
Gmail API adalah layanan yang memungkinkan aplikasi mengirim dan mengelola email secara otomatis melalui akun Gmail tanpa dilakukan secara manual oleh pengguna.

Fitur Fungsional
	Untuk mencapai tujuan sebagai asisten keuangan pribadi yang praktis, sistem Moneygement dilengkapi dengan serangkaian fitur utama yang mencakup pengelolaan transaksi secara real-time, pengaturan anggaran yang disiplin, hingga pemanfaatan kecerdasan buatan untuk analisis finansial yang mendalam. Rincian fungsionalitas tersebut dibagi ke dalam beberapa kategori kebutuhan sistem sebagai berikut:
Autentikasi dan Manajemen Pengguna: Sistem menyediakan fitur pendaftaran akun baru, mekanisme masuk (login) dan keluar (logout), pemulihan kata sandi yang terlupa, serta pengelolaan profil pribadi dan foto pengguna.
Manajemen Transaksi: Pengguna dapat mencatat data pemasukan dan pengeluaran, melakukan perubahan atau penghapusan data transaksi, menyaring riwayat berdasarkan filter tertentu, serta mengunggah bukti fisik transaksi dalam format gambar atau PDF.
Pengaturan Anggaran (Budgeting): Sistem memfasilitasi pengguna untuk menetapkan limit anggaran per kategori setiap bulan, memantau progres penggunaan dana secara langsung, menerima peringatan jika anggaran mendekati batas, dan menganalisis alasan terjadinya pengeluaran berlebih.
Dashboard dan Analitik: Halaman utama menyajikan ringkasan saldo total serta akumulasi pemasukan dan pengeluaran melalui grafik batang bulanan dan grafik pie kategori untuk membantu pengguna memahami kondisi keuangan mereka secara visual.
Laporan Keuangan: Sistem dapat menyusun laporan dalam periode harian, mingguan, maupun bulanan yang dapat diunduh oleh pengguna dalam format PDF, Excel, atau CSV.
Fitur Kecerdasan Buatan (AI): Menggunakan integrasi OpenAI API, sistem mampu menganalisis pola pengeluaran, memberikan saran penghematan otomatis, memprediksi estimasi pengeluaran bulan berikutnya, hingga merangkum laporan keuangan dalam bahasa manusia yang mudah dimengerti.
Sistem Notifikasi: Perangkat lunak memberikan pengingat harian untuk mencatat transaksi, notifikasi terkait status anggaran, serta pengingat jadwal tagihan rutin bulanan.
Pengaturan Aplikasi: Pengguna memiliki kendali untuk mengubah tema tampilan (gelap/terang), mengatur bahasa dan zona waktu, serta melakukan pencadangan data (backup).
Manajemen Administrator: Sisi admin berfungsi untuk mengelola akun pengguna, mengatur kategori transaksi standar, memantau statistik performa sistem, serta melayani permintaan bantuan teknis (support) dari pengguna.

Tabel 2.1 Source Code Helper Function
private function callGemini(string $prompt, ?string $imageBase64 = null, ?string $mimeType = null)
{
    $apiKey = env('GEMINI_API_KEY');
    
    // Setup payload (Text-only atau Multimodal/Gambar)
    if ($imageBase64 && $mimeType) {
        $contents = [[
            'parts' => [
                ['inline_data' => ['mime_type' => $mimeType, 'data' => $imageBase64]],
                ['text' => $prompt]
            ]
        ]];
    } else {
        $contents = [[
            'parts' => [['text' => $prompt]]
        ]];
    }

    // HTTP Request ke Gemini 2.5 Flash
    $response = Http::timeout(60)->post(
        "https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key={$apiKey}",
        [
            'contents' => $contents,
            'generationConfig' => [
                'temperature' => 0.7, // Kreativitas sedang
                'maxOutputTokens' => 4096,
            ]
        ]
    );

    return $response->json()['candidates'][0]['content']['parts'][0]['text'] ?? null;
}

}

Integrasi Frontend (JavaScript)
Di sisi tampilan (Blade), kita menggunakan AJAX/Fetch untuk memanggil API backend ini agar halaman tidak perlu refresh (loading state).
Contoh: Memanggil Insight di Dashboard
Tabel 2.5 Source Code Memanggil Insight
<div x-data="{ insight: 'Loading...', loading: true }" x-init="
    fetch('{{ route('ai.insight') }}')
        .then(res => res.json())
        .then(data => {
            insight = data.insight;
            loading = false;
        })
">
    <p x-text="insight"></p>
</div>

User buka Dashboard.
JS secara background request ke `/ai/insight`.
Laravel proses data -> kirim ke Gemini -> dapat teks.
Laravel balikkan JSON ke JS.

Gambar 4.21 Tampilan Admin Panel
Admin Dashboard pada aplikasi MoneyGement memiliki struktur navigasi yang serupa dengan dashboard pengguna, namun dengan tambahan menu Admin Panel yang berisi fitur khusus untuk memonitor dan mengelola sistem secara keseluruhan. Berikut adalah deskripsi rincian isi dari Admin Panel tersebut:
Statistik Sistem Utama: Bagian atas panel menampilkan empat kartu indikator performa sistem secara real-time, yaitu:
Total Users: Menampilkan jumlah keseluruhan pengguna yang terdaftar.
User Baru (Bulan Ini): Melacak pertumbuhan pengguna baru pada bulan berjalan .
Total Transaksi: Menampilkan akumulasi seluruh transaksi yang dilakukan di dalam sistem .
TXN Bulan Ini: Menampilkan jumlah aktivitas transaksi khusus pada bulan berjalan.

Menu Navigasi Pengelolaan: Terdapat tiga tombol akses cepat untuk fungsi administratif:
Kelola Users: Fasilitas untuk melihat, mengubah, atau menghapus data pengguna sesuai dengan Use Case "Mengelola User".
System Logs: Fitur untuk memantau catatan kesalahan (error logs) dan aktivitas sistem guna memenuhi kebutuhan "Memantau dan Memperbaiki Sistem".
User Dashboard: Tombol navigasi untuk kembali ke tampilan dashboard standar pengguna.

Daftar User Terbaru: Bagian bawah menampilkan tabel atau daftar pengguna yang baru saja mendaftar atau aktif, lengkap dengan informasi:
Identitas: Nama dan alamat email.
Role: Keterangan status akun (User atau Admin).
Waktu: Keterangan kapan akun tersebut terakhir aktif atau dibuat.





Tampilan Kelola User

Gambar 4.22 Tampilan Kelola User

Halaman Kelola User pada sistem MoneyGement merupakan antarmuka administratif yang digunakan oleh aktor Admin untuk melakukan moderasi dan manajemen terhadap seluruh akun pengguna yang terdaftar di dalam database. Berdasarkan tampilan antarmuka yang tersedia, berikut adalah deskripsi detail mengenai komponen dan fungsinya:

Informasi Ringkasan dan Navigasi
Status Total User: Di bagian atas halaman, sistem menampilkan jumlah total pengguna yang terdaftar.
Fitur Pencarian: Terdapat kolom pencarian fungsional bertajuk "Cari nama atau email..." yang disertai tombol "Cari" untuk mempermudah Admin menemukan data pengguna spesifik secara cepat.
Tombol Kembali: Terdapat tombol "Kembali" di pojok kanan atas untuk mengarahkan Admin kembali ke halaman utama Admin Dashboard.

Tabel Data Pengguna
Tabel utama menyajikan informasi mendalam mengenai setiap akun pengguna dengan kolom-kolom sebagai berikut:
User: Menampilkan inisial, nama lengkap, serta durasi sejak pengguna tersebut bergabung.
Email: Menampilkan alamat email lengkap yang terdaftar sebagai identitas unik pengguna di sistem.
Transaksi: Melacak jumlah aktivitas keuangan yang telah dilakukan oleh pengguna.
Status: Menunjukkan peran akun tersebut, apakah sebagai User biasa atau sesama Admin.

Fungsi Aksi Moderasi
Sistem menyediakan kontrol penuh bagi Admin untuk melakukan tindakan pada setiap akun melalui kolom Aksi:
Manajemen Role (Promote/Demote): Admin dapat mengubah peran pengguna melalui tombol "Promote" untuk menaikkan status menjadi Admin, atau tombol "Demote" untuk menurunkan status Admin menjadi User biasa.
Hapus Akun: Terdapat ikon tempat sampah berwarna merah yang memungkinkan Admin untuk menghapus data pengguna secara permanen dari database sesuai dengan wewenang yang didefinisikan dalam Use Case Diagram.
